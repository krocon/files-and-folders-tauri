Become a master of file management

I have been building file managers for myself since 2016 – first one that ran in the browser, now a real desktop app. FnF puts two folders side by side, lets you do everything with the keyboard and runs the slow work in the background while you go on.

Marc Kronberg

Keyboard first

Every function is an action with a name and a shortcut – type a few letters, press Enter.

The Command Palette finds any action and shows its key, so you learn the shortcuts on the way. The classic keys are where you expect them: F3 view, F5 copy, F6 move, F7 new folder, F8 delete.

Windows, Linux
Ctrl+Shift+P
macOS
⌘⇧P

Jobs in the background

Start a big copy and keep working – the window never freezes.

Copy, move, delete, pack and search run as jobs with progress, rate and remaining time. Pause, resume or cancel them; slow network drives and servers are handled the same way.

Windows, Linux
F5 F6 Ctrl+F11
macOS
F5 F6 ⌃K F6

Safe by default

Delete goes to the trash, nothing is overwritten without asking.

If a file already exists you see both versions with size and date and decide once – or for all further conflicts. Copies are written under a temporary name first, so there is never a half-written file under the real name.

Windows, Linux
F8 trash, Shift+F8 permanently
macOS
F8 trash, ⇧F8 permanently

Multi rename with preview and undo

Rename hundreds of files in one go – and see every new name first.

Name, extension, counter and date macros, case rules, search and replace with regular expressions, presets. Problems show up in the preview, and a finished rename can be undone.

Ctrl+M
macOS
⌘F6

All files of all subfolders in the same tab, with a Path column. Sort, mark, copy, delete or rename across all of them at once – the same key brings the normal view back.

Find identical files, similar photos in another size or quality, or similar comics. Rules like “keep the oldest” or “keep the higher resolution” mark the rest; you check each group with thumbnails before anything goes to the trash.

Open ZIP, TAR, 7z and RAR like any other folder.

Browse, view and open files inside, pack and unpack, with passwords that are only kept in memory. Archives from elsewhere are treated as hostile – no zip-slip, no zip-bombs.

Browse, copy in both directions, rename and delete like on your own disk. Passwords live only in your system keychain; host keys and certificates are checked, and plain FTP is marked as unencrypted.

Norton blue, paper white or your own

Eleven colour schemes come with the app: the eight classic designs of the earlier versions – Light, Paper, Bitbucket, Cypress, Blackboard, Coffee, Combat and Norton – plus modern light, dark and Crimson. The live editor checks every colour pair for WCAG contrast; schemes can be exported and shared.

macOS, Windows and Linux

One app, built with Tauri and Rust, with native menus on macOS and a keymap per system. The automated tests run on all three systems; a few platform details still need testing on real Macs and Windows PCs before the first release.

Questions

Is it free?

Yes. Files and Folders is open source under the MIT license – use it at home and at work, read the code, change it.

Where can I download it?

The first public release is still being prepared. Until then you can build the app from source with Node.js, pnpm and Rust – the steps are in the README. Releases will appear on GitHub.

Are the packages signed?

Not yet. The first packages will be unsigned: on macOS open the app with right-click, Open; on Windows choose More info, Run anyway in SmartScreen.

What happens with my data?

It stays on your computer. The app has no account, no telemetry and does not phone home. Server passwords are kept in the keychain of your system, archive passwords only in memory.

I used the earlier browser versions. Can I keep my settings?

Yes. The app imports shortcuts, buttons, file types, search patterns, tools and colour schemes of files-and-folders-mr, shows a preview first and keeps a backup of every file it changes.

Which languages?

English and German, switchable while the app runs.
